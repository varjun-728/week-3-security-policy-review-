## About

This project contains my Week 3 internship task on reviewing a hypothetical organization's security policy.

The objective of this task is to identify weaknesses and security gaps in an existing policy and recommend practical improvements to strengthen the organization's overall security posture.

## Topics Covered

* Security Policy Review
* Access Control
* Password and Authentication Security
* Multi-Factor Authentication
* Data Protection
* Acceptable Use
* Email and Phishing Security
* Endpoint Security
* Network Security
* Incident Reporting
* Security Awareness
* Backup and Recovery
* Third-Party Security
* Remote Access
* Security Monitoring
* Policy Governance
* Security Improvement Roadmap

## Key Outcome

The review identifies security weaknesses and provides practical recommendations categorized into immediate, medium-term, and long-term improvements.
